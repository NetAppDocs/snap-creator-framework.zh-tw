= 設定NetApp管理主控台資料保護功能的參數
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
設定NetApp管理主控台資料保護功能需要多個參數。

|===
| 參數 | 設定 | 說明 


 a| 
ntap_PM_update
 a| 
（是|否）
 a| 
可讓您開啟和關閉NetApp管理主控台資料保護功能更新、此更新會在NetApp管理主控台資料保護功能中登錄Snap Creator Snapshot複本。*附註：*如果啟用NTAP_PM_update、您必須設定NTAP_DFM資料集。



 a| 
ntap_dfm_data_set
 a| 
 a| 
列出儲存系統和NetApp管理主控台資料保護功能資料集、以建立磁碟區關聯；也就是控制器1：dataset1/vol1、vol2；控制器1：dataset2/vol3。



 a| 
ntap_PM_run備份
 a| 
（是|否）
 a| 
啟動NetApp管理主控台資料保護功能備份、檢查進度和狀態、並等待其完成。



 a| 
ntap_dfm_snapshot格式
 a| 
 a| 
使用NetApp管理控制台資料保護功能時，輔助快照副本格式的選用設定。此選項需要OnCommand 5.0 或更高版本。必填變數：

* 時間戳：%T


可選變數：

* 保留類型：%R
* 資料集標籤：%L
* 儲存控制器：%H
* 卷名：%N
* 應用特定數據：%A


如果未設定此選項，則使用NetApp管理控制台資料保護功能的預設命名約定。命名規則只能在建立資料集時設定。

|===
